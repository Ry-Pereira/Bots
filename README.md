## ▶️ How to Run the Projects 🏃‍♂️

1. 📥 Clone the repository:

```bash
git clone <your-repository-url>
```

2. 📂 Navigate into the folder:

```bash id="bots1"
cd Bots_Repository
```

3. 📁 Go into any bot folder:

```bash id="bots2"
cd bot-1
```

4. ▶️ Run the bot (example):

```bash id="bots3"
bash bot_script.sh
# or
python bot_script.py
# or
node bot_script.js
```
